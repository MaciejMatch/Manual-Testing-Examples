# Manual Testing Examples – Demoblaze Demo Store

This repository contains practical examples of manual testing documentation for the **Demoblaze demo e-commerce store** (https://www.demoblaze.com).  
It demonstrates comprehensive test case design, execution, and bug reporting for a real application.

---

## 📝 Project Overview

**Objective:**  
Validate core functionalities of the Demoblaze demo store through structured manual testing, including registration, login, product selection, cart management, and checkout.

**Application Under Test:**  
Demoblaze - https://www.demoblaze.com  
A demo e-commerce platform for learning and testing purposes.

**Scope:**  
- ✅ User Registration & Authentication
- ✅ User Login & Logout
- ✅ Product Browsing & Filtering
- ✅ Shopping Cart Management  
- ✅ Checkout Process
- ✅ Form Validation Testing
