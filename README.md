# Manual Testing Examples – Demoblaze Demo Store

This repository contains practical examples of manual testing for the **Demoblaze demo e-commerce store** (https://www.demoblaze.com).  
It demonstrates step-by-step execution of end-to-end test scenarios.

---

## 📝 Project Overview

**Objective:**  
Validate core functionalities of the Demoblaze demo store through manual testing, including registration, login, product selection, cart, and checkout.

**Scope:**  
- User registration  
- User login  
- Browsing and selecting products  
- Adding products to cart  
- Viewing cart contents  
- Checkout process
