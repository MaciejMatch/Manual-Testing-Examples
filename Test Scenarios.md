## TS-01: User Registration
User can create a new account successfully.

## TS-02: User Login
Registered users can log in to the system.

## TS-03: Browse and Select Products
Users can browse categories and select products.

## TS-04: Add Products to Cart
Users can add one or more products to the shopping cart.

## TS-05: View Cart
Cart displays correct product details, quantity, and prices.

## TS-06: Checkout
Users can complete the purchase and see confirmation.
